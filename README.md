# SMS Spam Classifier

This is a beginner-friendly machine learning project that uses a Naive Bayes classifier to detect whether a text message is spam or not. It was built using Python, pandas, scikit-learn, and a dataset of SMS messages.

## Features

- Cleaned and labeled SMS data
- Converts messages into word count vectors
- Trains a Naive Bayes model with 98%+ accuracy
- Interactive CLI for live spam predictions
- Beginner-readable code with comments

## Technologies Used

- Python 3
- pandas
- scikit-learn
